Integración Bot Externo

Para conectar tu bot de WhatsApp/MercadoLibre (alojado en otra carpeta) con el inventario de esta tienda, utiliza el siguiente Endpoint API:

GET .../api/bot/check-stock?q=TERMINO_BUSQUEDA

También puedes buscar por código exacto usando ?code=CODIGO123.
